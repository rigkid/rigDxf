# rigDxf

![preview](examples/dxf/img/preview.png)

ASCII DXF → `ParsedPathDoc` / `CPaths`.

Supports `LINE`, `LWPOLYLINE`, `CIRCLE`, `ARC`, and DXF layer names → `PathSourceLayer`.

Depends on **rigPlotComponent**. Headless gate: `tools/dxf_smoke.cpp`.

[API/docs](https://rigkid.github.io/rigDxf/)
